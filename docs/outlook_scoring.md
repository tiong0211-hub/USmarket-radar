# M12 "오늘 국장은?" 스코어링 로직

화면의 "오늘 국장은?"은 **코스피 시가 갭 방향**(시가 vs 전일 종가)만 판단한다.
장중 흐름(시가 → 종가)은 예측하지 않고, 그 사실을 고정 문구로 함께 보여준다.
LLM은 방향을 정하지 않는다(M8은 M12 결과를 그대로 받아 문장만 쓴다).

- 코드: `src/radar/analytics/outlook.py`
- 설정: `config/settings.yaml` → `outlook`
- 계수·적중률: `data/outlook_model.json` (매달 자동 갱신)

## 1. 입력

전날 밤 미국장 종가 기준 등락률(%) 3개.

| 입력 | 출처 | 왜 쓰나 |
|---|---|---|
| 반도체(SOX) | M1 지표 `SOX` | 코스피 갭과 상관이 가장 큼(0.58). 나스닥100(0.54)보다 큼 |
| 한국 ETF(EWY) | M4 섹터 ETF `EWY` | 미국 시간에 거래된 한국 주식 바스켓(상관 0.49) |
| VIX | M1 지표 `VIX` (등락률) | 위험 회피 강도(상관 −0.41) |

빠진 신호와 이유(2026-11 연구, 944거래일):
- 나스닥100: SOX와 겹쳐 추가 설명력 없음.
- 원/달러: 갭과 상관 0.07.
- 마이크론, 삼성전자 런던 GDR: 넣어도 적중률 변화 없음(74% → 74~75%).

## 2. 점수

```
점수 = 절편 + a × SOX등락률 + b × EWY등락률 + c × VIX등락률
```

- 점수는 "예상 갭(%)"에 해당하는 값이지만 **화면에 숫자로 표시하지 않는다**(갭 % 수치 표시 금지 규칙).
- 계수는 최근 3년 데이터로 최소제곱 회귀(OLS)한 값이다.
  2026-11-09 보정값: 절편 0.116, SOX 0.2166, EWY 0.0923, VIX −0.0101.
  즉 SOX가 +1%면 점수 약 +0.22, EWY가 +1%면 약 +0.09.

## 3. 방향 판정

| 조건 | 표시 |
|---|---|
| 점수 ≥ +0.3 | 갭상승 우세 |
| 점수 ≤ −0.3 | 갭하락 우세 |
| \|점수\| < 0.3 | 보합 우세 |
| \|점수\| ≥ 1.0 | 위 방향에 "· 강한 신호" 추가 |

기준값 0.3·1.0은 `flat_band_pct`, `strong_pct`.
미국장 휴장일에는 판정하지 않는다.

## 4. 적중률 (화면에 같이 표시)

- 정의: 보합이 아닌 판정을 낸 날 중, 판정 방향과 실제 시가 갭 부호가 같은 날의 비율.
- 일반 신호와 강한 신호를 따로 계산하고, 그날 판정에 해당하는 값을 보여준다.
- **표본 외 채점**: 최근 12개월은 계수 추정에서 빼고 채점에만 쓴다. 그 이전 데이터로 만든 계수로 최근 12개월을 맞혀 본 결과다.
- 채점이 끝나면 전체 3년으로 계수를 다시 추정해 실제 운영에 쓴다.

2026-11-09 보정 결과(채점 2025-11-14 ~ 2026-11-09):

| 구분 | 일수 | 적중률 |
|---|---|---|
| 방향 판정(일반) | 155 | 82.6% |
| 강한 신호 | 30 | 83.3% |
| 보합 판정 | 81 | (채점 안 함) |

## 5. 매달 재보정 (자동)

- `.github/workflows/calibrate.yml`이 매달 2일 03:00 KST에 실행한다.
- `python -m radar.analytics.outlook` 실행 → 코스피 시가·종가(FinanceDataReader `KS11`)와 SOX·EWY·VIX(yfinance)를 받아 2·4절을 다시 계산한다.
- 결과를 `data/outlook_model.json`에 커밋한다. 화면에는 "MM/DD 보정"으로 날짜가 표시된다.
- 실패하면 지난달 파일을 그대로 쓰고, 워크플로 실패 메일이 간다.
- 수동 실행: GitHub Actions → calibrate-outlook → Run workflow.

## 6. 한계

- 장중 흐름은 밤사이 공개 데이터로 예측되지 않았다(방향 적중률 50%). 그래서 판단하지 않는다.
- 갭은 평균적으로 되돌려지지 않았다. 다만 "갭상승 후 횡보"는 흔하다
  (나스닥 +1% 다음 날: 갭상승 91%, 장중 상승 47%).
- 야간선물·외국인 수급은 넣지 않았다(2026-11-09 사용자 결정: 예측용 대시보드가 아니므로 범위 밖).
